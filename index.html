Manual Transit Protocol

  1. Consult the Directory or Star Chart for your desired coordinate sequence.
  2. Input the precise 4-symbol sequence using the Sequence Input Console.
  3. Observe the mechanical chevrons physically lock each coordinate in place.
  4. Press the ENGAGE activator to initialize the transit corridor.

Express Transit Tokens

For rapid deployment, utilize the Express Tokens located next to each destination in the Directory. Inserting a token bypasses manual entry and sequentially locks the chevrons for you.
