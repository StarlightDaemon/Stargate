Lumina Grove Operator Reference

Manual Dial: Select exactly 4 symbols from the connection lattice. The network will route and lock each node. Press ENGAGE to open the conduit.

Quick-Dial: Select a pre-mapped resonance to instantly dial and engage.

Ward Lock: When active, prevents the conduit from opening (protects against unstable connections).

Disengage: Sever the active connection and return the network to dormancy.
