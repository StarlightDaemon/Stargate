# CARAVELLE — Pan-Continental Travelways Portal Salon

An interactive novelty portal-dialing website: the Caravelle, a Pan-Continental Travelways portal salon built into a 1937 cabinet (Belmont Instrument Works, Cabinet No. 9). The salon's directory carries a short board of fictional destinations — Port Vermilion, Lakeshore Pavilion, New Castile, Caldera Vista, Aerodrome Nine, The Palisades — dialed from a closed salon plate through to an open cabinet.

Everything here is fictional and fully client-side: no backend, no server process, no network calls, no real destinations.
