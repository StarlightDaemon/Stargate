# _sequestered — Retired, Closed, and Deprioritized Gate Builds

This folder contains retired, closed, or deprioritized gate builds. They are
**NOT part of the active development workload** and are **NOT being maintained
or updated**. The only exception to this no-touch policy is a security audit
or an equivalent explicitly-scoped review — nothing else justifies modifying
anything in this folder.

## Builds

- **Stargate_low_magic** — Retired: operator review found a cartoonish, shape-built look (resembling a child's video game rather than a physical device); traced to machine-perfect, evenly-spaced, identically-sized repeated elements (uniform grids, symmetric icon-like arrangements) reading as mobile-app UI-kit grammar rather than diegetic objects. Motion-easing and color-palette fixes did not resolve it.
- **stargate_low_magicv2** — Retired: second attempt at Low Magic, same unresolved rendering issue.
- **stargate_dieselpunk** — Retired: physical-material rendering never resolved; theme formally retired from active development.
- **stargate_dieselpunkv2** — Retired: second attempt, same category of issue, theme formally retired.
- **stargate_steampunk** — Retired: operator review found the same cartoonish, shape-built look (resembling a child's video game rather than a physical device), traced to machine-perfect, evenly-spaced, identically-sized repeated elements (uniform grids, symmetric icon-like arrangements) reading as mobile-app UI-kit grammar rather than diegetic physical objects; motion-easing and color-palette fixes did not resolve it. A separate, later digital-native reframe of Steampunk succeeded and remains active elsewhere.

- **stargate_low_scifi_maintenance** — Deprioritized: functional after a cleanup pass, but its control complexity deliberately exceeds this project's standard cap by documented design choice; carries pending uncommitted work not yet reviewed.
- **stargate_atompunk** — Deprioritized for hub-site ordering only, no known defects.
- **stargate_cyberpunk** — Deprioritized for hub-site ordering only, no known defects.
