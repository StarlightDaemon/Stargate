# _sequestered — Retired Gate Builds

This folder contains retired gate builds. They are **NOT part of the active
development workload** and are **NOT being maintained or updated**. The only
exception to this no-touch policy is a security audit or an equivalent
explicitly-scoped review — nothing else justifies modifying anything in this
folder.

Every build below is Retired. Where a folder's own CHANGELOG.md/README.md
names a real, specific defect, that defect is described here. Where a
folder's own documentation names no defect, that is stated plainly rather
than invented to match its neighbors.

## Builds

- **Stargate_low_magic** — Retired: operator review found a cartoonish, shape-built look (resembling a child's video game rather than a physical device); traced to machine-perfect, evenly-spaced, identically-sized repeated elements (uniform grids, symmetric icon-like arrangements) reading as mobile-app UI-kit grammar rather than diegetic objects. Motion-easing and color-palette fixes did not resolve it.
- **stargate_low_magicv2** — Retired: second attempt at Low Magic. Its own CHANGELOG.md documents only a [1.0.0] "Added" section — no Known Issues or Fixed entries — so no specific defect is recorded for this build.
- **stargate_dieselpunk** — Retired from active development. No CHANGELOG.md exists for this build, and its README.md documents features only; no specific defect is recorded.
- **stargate_dieselpunkv2** — Retired: its own CHANGELOG.md documents a "Known Issues" entry stating physical-material rendering was never resolved, retired for the same unresolved rendering issue as stargate_dieselpunk.
- **stargate_steampunk** — Retired: operator review found the same cartoonish, shape-built look (resembling a child's video game rather than a physical device), traced to machine-perfect, evenly-spaced, identically-sized repeated elements (uniform grids, symmetric icon-like arrangements) reading as mobile-app UI-kit grammar rather than diegetic physical objects; motion-easing and color-palette fixes did not resolve it. A separate, later digital-native reframe of Steampunk succeeded and remains active elsewhere.
- **stargate_cyanotype_geodetic** — Retired: an auto-activation bug was fixed, but the portal/aperture visual effect on activation was never confirmed to render perceptibly; closed with the issue unresolved.
- **stargate_low_scifi_maintenance** — Retired from active development. Its own CHANGELOG.md's [Unreleased] "Fixed" section lists items already resolved during a cleanup pass, not an open defect; no specific defect is recorded.
- **stargate_atompunk** — Retired from active development. Its own CHANGELOG.md documents features and a compliance pass only; no specific defect is recorded.
- **stargate_cyberpunk** — Retired from active development. Its own CHANGELOG.md documents features, a compliance pass, and a visual-polish pass only; no specific defect is recorded.
