# CAÏSSA-9 — Neural Recursion Strategy Analysis Workstation

An interactive novelty portal-dialing website built around CAÏSSA-9, a neural-recursion strategy workstation of the Institute for Deep Combinatorial Analysis (Minimax Core v9.42-AVX512). A destination is dialed as a 7-ply tactical combination: twelve candidate glyphs lock in one at a time on the radial Search-Tree Ring, its eight concentric plies sprouting candidate branches and pruning under live alpha-beta sweeps as the principal-variation node anchors. A completed line arms the console at PENDING COMMIT rather than firing on its own. Six preloaded tactical presets — a verified Grandmaster Mate canon and a tier of speculative neural hypotheses — replay their line through the same per-ply lock as manual dialing.

Everything here is fictional and fully client-side: no backend, no server process, no network calls, no real destinations.
