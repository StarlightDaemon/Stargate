# Lumina Grove — Bioluminescent Conduit Lattice

An interactive novelty portal-dialing website built as the Lumina Grove portal interface: a bioluminescent conduit lattice dialed through a 9-chevron system that wakes a living-surface portal effect on activation. Six quick-dial presets carry known routes, a Ward Lock safety system guards the lattice against an unwanted opening, and an operator reference modal documents the grove's controls.

Everything here is fictional and fully client-side: no backend, no server process, no network calls, no real destinations.
