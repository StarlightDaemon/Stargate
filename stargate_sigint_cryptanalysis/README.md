# Station VORTEX-9 — Cryptanalysis & Key Recovery Workstation

An interactive novelty portal-dialing website run from Station VORTEX-9, the signals-intelligence workstation of the Directorate of Signal Cryptanalysis & Key Recovery (DSCR). Dialing is a key-recovery hunt: eight sub-key registers strobe candidate glyphs at 60Hz across a circular Key-Space Search Ring, ten rotor-permutation sectors wide, while a collapsing Shannon-entropy heatmap arc counts down from 2³² toward zero as eigenvalues pin. A completed key leaves the console armed and READY rather than decrypting on its own. An OPSEC Channel Compromise interlock, released by default, blocks decryption outright when tripped, and an Emergency Sever instantly purges the keystream. Six preloaded intercepts span a High-Confidence Relays tier and a Suspect/Hostile Streams tier.

Everything here is fictional and fully client-side: no backend, no server process, no network calls, no real destinations.
