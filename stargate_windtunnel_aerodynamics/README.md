# Aeolos Stagnation Plenum (ASP-9) — Transonic Aerodynamic Test Console

An interactive novelty portal-dialing website built around the Aeolos Stagnation Plenum (ASP-9), the central transonic and supersonic aerodynamic flight test facility of the Aeolos High-Speed Aerodynamics Laboratory. Dialing corresponds to aligning six variable-pitch flow-straightener guide vanes around a 12-sector nozzle annulus and matching static-to-dynamic pressure ratios across a multi-port pitot-static rake, drawing boundary-layer suction to eliminate turbulent separation. Completing the sixth sector arms the plenum into `PLENUM ARMED / READY TO FIRE` without auto-firing — the operator must deliberately command flow initiation via the dedicated `INITIATE TRANSONIC RUN` control, with `EMERGENCY BLOWDOWN DUMP` reachable at every stage. A Choke Gate Safety Interlock, released by default, inhibits blowdown initiation with flashing amber hazard banners and acoustic sirens when engaged. The Aerodynamic Test Matrix Registry provides calibrated destination run profiles across validated transonic airfoil sweeps, supercritical shock-free polars, and hypersonic waverider geometries with paced machine-cadence auto-dialing.

Everything here is fictional and runs completely client-side in the browser: zero backend requirements, zero external asset dependencies, procedural Web Audio sound synthesis, and real-time canvas-based vector Schlieren optical flow visualization.
