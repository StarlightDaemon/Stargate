# Stargate

A gallery of original, client-side novelty portal consoles - each
one a small, self-contained interactive build exploring the same
core idea (a ring, a set of symbols, a way to dial somewhere)
through a different visual and thematic lens.

**[Browse the full gallery ->](https://starlightdaemon.github.io/Stargate/)**

## What this is

Every entry here is a standalone, framework-free HTML/CSS/JS
build - no dependencies to install, no build step to run, just
open it and dial. Themes range from steampunk and cyberpunk
reinterpretations to a chess-engine visualizer, a cryptanalysis
workstation, a deep-sea submersible pilot console, and dozens of
others, each with its own console aesthetic and dialing logic.

Not everything here is finished or polished. The gallery marks
each build's real status - live, known-issue, or retired - rather
than hiding the ones that didn't fully come together. What you
see is what actually exists.

## Structure

- `hub/` - the gallery site itself: scans every build, generates
  the catalog, and renders it as a browsable grid.
- `stargate_*/` - each individual build, self-contained and
  servable on its own.
- `_sequestered/` - retired builds, kept for the record rather
  than deleted.

## Origins

This collection began as a fan novelty project loosely inspired
by the Stargate franchise. Its flagship build has since moved
toward an entirely original design - original ring, original
glyph system, original destinations. This project is not
affiliated with, endorsed by, or connected to MGM or the Stargate
franchise.
